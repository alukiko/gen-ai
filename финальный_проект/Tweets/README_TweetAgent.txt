
Tweet Engagement Prediction & Agent Assistant

Описание проекта

Данный проект включает в себя инструменты и модели для оценки вовлечённости твитов и интеллектуального агента, способного предлагать улучшения твитов на основе прогнозируемого результата. Это может быть использовано в системах цифрового маркетинга, SMM-агентах и автоматизированных помощниках.

Содержимое

| Файл / Папка                  | Назначение                                                                 |
|------------------------------|----------------------------------------------------------------------------|
| regressor.ipynb              | Jupyter-ноутбук с обучением моделей для оценки вовлечённости               |
| agent_tweets_halper.ipynb    | Ноутбук с реализацией агента по оптимизации твитов                         |
| Twitterdatainsheets.csv      | Датасет с твитами и метаинформацией                                       |
| random_forest_model.pkl      | Сериализованная модель RandomForestRegressor, показавшая лучшие метрики   |
| engagement_score.pkl         | Целевая переменная (оценка вовлечённости) для модели                       |
| weekday_ohe.pkl              | OneHotEncoder для признака Weekday                                        |
| X_combined.pkl               | Скомбинированные признаки (BERT + дата/время)                              |
| catboost_info/               | Вспомогательные файлы от обучения модели CatBoost                         |

Возможности

- Прогноз вовлечённости твита до публикации  
- Агент, улучшающий твиты и подбирающий лучшее время  
- Использование BERT, ML-моделей (RandomForest, CatBoost, др.)  
- Интеграция через функцию @tool в LangChain

🔐 API-ключ для запуска агента

Для работы агента по улучшению твитов требуется API-ключ для доступа к языковой модели (LLM), которая обрабатывает запросы и предлагает улучшения.

В работе используется API - VseGPT
